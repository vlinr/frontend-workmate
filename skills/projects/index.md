# Projects Skills

## 说明

- 本目录用于存放 Stage 1 的项目扫描技能与项目技能索引说明。
- 项目级可复用能力以标准项目技能产物的形式统一复用。
- 本目录也包含 Stage 1 使用的项目扫描技能：`project-scan-profile`。
- 主流程进入 Stage 1 时，不只检查这里，还应同时检查当前工作区已有的历史项目技能候选与标准项目技能产物。
- 若用户直接提供项目 skills / 项目文档 / UI 框架资料，应优先吸收并归档到标准项目技能产物中，再决定是否需要内部生成。
- 若已有候选技能仍有效，则直接引用；若不存在可复用候选，再通过项目扫描生成或刷新。

## 命名规范

- 目录命名：`<project-slug>/`
- 文件命名：统一为 `SKILL.md`
- frontmatter `name`：统一为 `<project-slug>-project-skill`
- `project-slug` 优先使用项目根目录名；若存在冲突，再追加稳定业务前缀

## 发现顺序

1. 先检查当前工作区已有的项目技能候选，包括历史技能目录与已生成的项目技能产物
2. 再选择描述中与当前项目结构最匹配的项目技能直接复用
3. 若仍未找到，则进入项目扫描并创建新项目技能
