# 状态更新指南

## 阶段进入时更新

找到对应任务的状态块（`<!-- TASK_{任务ID}_START -->`），更新：
- `**正在执行**: {阶段名称}`
- `**阶段**: stage{N}`
- `**状态**: in_progress`
- `**下一步**: {下一步动作}`
- 阶段进度：将当前阶段移到"进行中"

## 阶段完成后更新

- `**状态**: completed`（或 `waiting_user`）
- 阶段进度：将当前阶段移到"已完成"，下一阶段移到"进行中"

## 回退时更新

- `**阶段**: stage{目标阶段}`
- `**状态**: in_progress`
- `**重置阶段**: [stageX, stageY, ...] → 待重新执行`
- 阶段进度：将后续阶段移到"待重新执行"

## 任务查找规则

更新状态时：
1. 从上下文获取 `current_task_id`
2. 查找 `<!-- TASK_{任务ID大写}_START -->`
3. 若找到 → 更新该状态块
4. 若未找到 → 新增任务状态块

## 任务ID携带机制

**用户只输入需求，任务ID通过 AI 输出自动携带**

### 任务ID携带方式

| 携带来源 | 说明 |
| --- | --- |
| 上下文引用 | 用户引用了先前 AI 输出（首行包含 `任务ID: task_xxxxxxxx`） |
| IDE 自动携带 | IDE 会话管理自动携带上一轮输出的任务ID |
| 无携带 | 新会话第一条输入，无任何任务ID上下文 |

### 判断逻辑（第一步）

**收到用户输入后，首先检查任务ID携带情况**：
| 携带情况 | 后续动作 |
| --- | --- |
| 有任务ID携带 | → 读取状态文件 → 找到对应任务 → 继续 |
| **无任务ID携带** | → **创建新任务**（新会话第一条输入） |

**重要**：
- 用户不会手动输入任务ID，只输入需求内容
- 任务ID通过 AI 输出首行携带，后续对话通过引用/上下文自动传递
- 检测到"无任务ID携带" = 新会话第一条输入 = 创建新任务

### 第二步分支

**A分支（有任务ID携带）**：
- 读取状态文件 → 查找 `<!-- TASK_{任务ID大写}_START -->`
- 继续该任务

**B分支（无任务ID携带）**：
- 生成新任务ID `task_{新随机ID}`
- 读取状态文件 → 新增任务块
- 从 Stage 0 开始执行
- **首行输出携带任务ID** `[阶段名称] 任务ID: task_xxx`

### 示例流程

**新会话第一条**：
```
用户："添加用户管理模块"（无任务ID携带）
AI：第一步检查 → 无携带 → 创建新任务 task_abc123 → Stage 0
AI 输出首行："[初始化] 任务ID: task_abc123"
```

**已有会话继续**：
```
用户："继续，这里需要改一下"（任务ID已在上轮携带）
AI：第一步检查 → 有携带 task_abc123 → 继续 task_abc123
```

### 设计要点

- **AI 输出首行携带任务ID**：确保任务上下文可追踪
- **IDE/引用自动传递**：任务ID在对话中自动携带，用户无需手动输入
- **无携带 = 新任务**：最简单的判断逻辑
