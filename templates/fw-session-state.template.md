# 状态更新指南

## 阶段进入时更新

找到对应任务的状态块（`<!-- TASK_{任务ID}_START -->`），更新：
- `**正在执行**: {阶段名称}`
- `**阶段**: stage{N}`
- `**状态**: in_progress`
- `**下一步**: {下一步动作}`
- 阶段进度：将当前阶段移到"进行中"

## 阶段完成后更新

- `**状态**: completed`（或 `waiting_user`）
- 阶段进度：将当前阶段移到"已完成"，下一阶段移到"进行中"

## 回退时更新

- `**阶段**: stage{目标阶段}`
- `**状态**: in_progress`
- `**重置阶段**: [stageX, stageY, ...] → 待重新执行`
- 阶段进度：将后续阶段移到"待重新执行"

## 任务查找规则

更新状态时：
1. 从上下文获取 `current_task_id`
2. 查找 `<!-- TASK_{任务ID大写}_START -->`
3. 若找到 → 更新该状态块
4. 若未找到 → 新增任务状态块
